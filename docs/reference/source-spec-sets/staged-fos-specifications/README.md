# Founder Operating System - Clean Specification Set

This package consolidates and cleans the attached Founder Operating System documents and corrects the earlier treatment of marketing as a late-stage function.

## Documents

1. `00_FOS_Design_and_Architecture.md` - system principles, agent teams, shared memory, autonomy, build order, and operating model.
2. `01_FOS_Product_and_Phased_Implementation_Specification.md` - product objectives, architecture, phase plan, gates, metrics, and revised phase placement for marketing and communications.
3. `02_FOS_Phases_0-1_Technical_Specification.md` - implementation-grade Phase 0 and Phase 1 handoff, including beta launch, LinkedIn, Substack, campaign, and attribution foundations.
4. `03_FOS_Phases_2-6_Technical_Specification.md` - implementation-grade specifications for activation, editorial operations, QA, scaled demand, intelligence, and founder coordination.
5. `04_FOS_Marketing_and_Communications_Technical_Specification.md` - authoritative detailed specification for LinkedIn posts and carousels, Substack papers, newsletters, website copy, email, webinars, release communications, engagement, repurposing, and attribution.

## Authority and conflict resolution

- `FOS-ARCH` controls architectural principles.
- `FOS-PROD` controls phase priorities and business objectives.
- `FOS-P01` and `FOS-P26` control phase-specific implementation.
- `FOS-MCOM` controls marketing and communications implementation details.
- Where a legacy sentence suggests that marketing begins only in Phase 4, the revised phase map and `FOS-MCOM` take precedence.

## Core correction

Marketing and communications now begin in Phase 0 with audience, voice, channel, CTA, claims, campaign, and attribution foundations; execute beta-launch communications in Phase 1; become a recurring founder editorial engine in Phase 2; produce release and customer proof in Phase 3; and scale in Phase 4.
